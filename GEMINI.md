# EIU MedLabs Agent Context

Before working in this repository, read and follow `AGENTS.md` and `docs/DOCUMENTATION_AUTHORITY.md`.

- `AGENTS.md` is authoritative for agent navigation, engineering rules, and tooling. `GEMINI.md` does not impose separate mandatory Graphify, GitNexus, or re-indexing requirements.
- `docs/DOCUMENTATION_AUTHORITY.md` defines the strict document precedence hierarchy and repository ownership.
- For UI modernization, responsive, accessibility, design-system, or frontend-polish work, read in order:
  1. `docs/ui-modernization/README.md`
  2. `docs/ui-modernization/CURRENT.md`
  3. `docs/ui-modernization/TRACKER.md`
  4. `docs/ui-modernization/DECISIONS.md`
- If the user gives a generic continuation request, follow the resume protocol in `AGENTS.md` and `docs/ui-modernization/README.md`. An explicit current user request always takes precedence.
